Repositorio de prácticas de desarrollo móvil con Flutter y Dart.

## Estructura

- `cosecha_app/`: aplicación Flutter de apoyo al registro de cosecha.
- `ejercicios_dart/`: ejercicios de refuerzo de sintaxis de Dart.
  - `precios.dart`: conversión de USD por quintal a USD por kilogramo.
  - `tabla.dart`: tabla de cajas para uno a cinco lotes mediante ciclos anidados.
  - `par_impar.dart`: clasificación de números de parcela con una función flecha.
  - `clima.dart`: nulabilidad, operador `??` y estructura `switch`.

## Ejecución de los ejercicios

```bash
dart run ejercicios_dart/precios.dart
dart run ejercicios_dart/tabla.dart
dart run ejercicios_dart/par_impar.dart
dart run ejercicios_dart/clima.dart
```

## Ejecución de la aplicación Flutter

```bash
cd cosecha_app
flutter pub get
flutter run
```
